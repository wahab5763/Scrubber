# AI usage disclosure

## GitHub Copilot

GitHub Copilot in VS Code was used as an AI assistant during development. The prompts used for project guidance are listed in prompts.txt.

The specific Copilot model was not recorded (free version).

## AI model used by the app

The app calls the Groq API using the model `openai/gpt-oss-20b`. It can help interpret chat questions and select or phrase supported findings. Python performs the financial calculations locally; the model does not calculate transaction totals.
